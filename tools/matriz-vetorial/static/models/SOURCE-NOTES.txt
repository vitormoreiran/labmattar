NATIVE ASSETS — LAB MATTAR

All files were produced from read-only copies of the original Blender geometry.
Original source: acervo-local/Sequencia-1.blend
No original file was saved or changed.

CORE
- glb/p1-light.glb ... p9-light.glb: nine native light meshes, un-decimated.
- glb/m.glb, a1.glb, t1.glb, t2.glb, a2.glb, r.glb: six native letter volumes split by connected components from Ativo 11.001. Every original component is preserved.
- Each file has one mesh and one node. Letters have one optional morph target named Native Key 1, default weight zero.
- core-manifest.json: source IDs, geometry counts, normalization and baked native phase.
- word-layout.json: use its positions and relative scales to restore the source word's proportions, rather than fitting every glyph independently to the same height.

DENSE BRANCH
- glb-dense/p1-dense.glb ... p9-dense.glb: dense native volumes reduced from about1.5million faces each to60k faces each. Approximately1.08MB per asset, no textures or Draco decoding required.
- dense-manifest.json: provenance and normalization.
- dense-projection-comparison.json: original versus reduced pixelmask intersection/union at0 and90degrees. Range .9980–.99995 at384px. Other views were not exhaustively compared.

COORDINATES
- GLTF +Y is vertical; look from +Z toward the origin.
- Canonical front is asset rotationY=0. Positive turns are around Y.
- All models have front geometry height2. Native turn axes are retained; only vertical centering, normalization and source word splitting were applied.
- P2's initial source phase180degrees is ALREADY BAKED into both light and dense models. Do not add180degrees again. Its relative canonical angle0 faces the same direction as the SVG.
- SVG-to-model conversion for projected dense profiles: xWorld=(svgX-512)*.003125; yWorld=(512-svgY)*.003125. Camera view height3.2, origin[512,512]. Full viewBox1024 is intentional; do not silently auto-fit away its native axis alignment.

PROJECTED PROFILES
- profiles-dense/p1-dense-90.svg ... p9-dense-90.svg were orthographically projected from exported dense GLBs at relative90degrees, rendered at1024px, boundary traced and simplified0.75px.
- fill-rule evenodd retains native holes, including the small P8 hole. P3 preserves two additional small native contours.
- profiles-dense/manifest.json provides SVG pixel/world bounds and axis anchor.
- profiles-dense/validation.json compares re-rasterized SVG versus native projection: .99765–.99877 pixelmask IoU.
